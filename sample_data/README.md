# Sample workbooks

Two real, committed loads (not the full 20 clean + 30 defect benchmark
set, which is regenerated by `scripts/run_gate_benchmark.py` and not
tracked) so a reader can open an actual `.xlsx` without running anything:

- `clean_load_month00/`: a full 6-source clean load (month 0) that
  publishes. Open `shipment_log.xlsx` in Excel to see the merged 2-row
  header (`Order ID` / `Plant` / `Month` each span both header rows;
  `Shipment` spans two columns in row 1 over `Quantity` and `Unit` in
  row 2) and the per-country tabs (`IT`, `NL`, `SG`).
- `defect_merged_header_misaligned_month03/`: the same shape with one
  seeded defect, a `merged_header_misaligned` fault on
  `returns_register.xlsx`'s `SG` tab (the row-2 labels under the
  `Return` merge are swapped, so the sheet's physical columns no longer
  match the contract's canonical order). `python scripts/run_gate_benchmark.py`
  quarantines this load and names the exact failing check.

Both were generated by `reconcilegate.datagen` with the repo's fixed
seed, so re-running the generator reproduces them exactly.
